# UIDAI EDA Project

## Overview

This project performs **Exploratory Data Analysis (EDA)** on UIDAI-related datasets to gain insights into enrollment, demographic information, and biometric records. The analysis helps identify patterns, trends, and data quality issues using Python data analysis libraries.

## Dataset

The project uses the following datasets:

* `biometric.csv` – Biometric-related information
* `demographic.csv` – Demographic details
* `enrolment.csv` – Enrollment data

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/UIDAI_EDA.git
```

2. Navigate to the project directory:

```bash
cd UIDAI_EDA
```

3. Install required packages:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

## Usage

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `new1.ipynb` and run the cells sequentially.
